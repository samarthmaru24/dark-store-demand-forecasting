# Dark Store Demand Forecasting

Predicts demand for the next 14 days for quick-commerce dark stores.

## Data sources

- Store Sales – Time Series Forecasting (Kaggle): https://www.kaggle.com/competitions/store-sales-time-series-forecasting/data
- Online Retail II (UCI): https://archive.ics.uci.edu/dataset/502/online+retail+ii
- Weather: Open-Meteo historical API (fetched by code)
- Indian festivals: Python `holidays` library

> **Note:** Data files are not in the repo; download them into `raw/`.
